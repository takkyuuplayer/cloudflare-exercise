# 14. AI: Workers AI・AI Gateway・Vectorize

- 前提: 08（10, 11 があると題材にしやすい）

## ゴール

- Workers AI でモデルを呼び出せる

## 演習

### 14-1 `[Code]` テキスト生成

AI バインディングでテキスト生成モデルを呼び、ストリーミングでレスポンスを返す API を作る。

**完了条件:** `curl -N` でトークンが逐次届くことを確認する。

### 14-2 `[Dashboard]` AI Gateway を挟む

AI Gateway を作り、14-1 の呼び出しを Gateway 経由にする。キャッシュとレート制限を設定する。

**完了条件:** Dashboard のログで、同じプロンプトの 2 回目がキャッシュヒットしたことを確認できる。

### 14-3 `[Code]` RAG

1. 自分の学習メモ（`PROGRESS.md` や `labs/*/NOTES.md`）を分割して Embedding を作り、Vectorize に登録する
2. 質問を受けたら類似文書を検索し、それを文脈としてテキスト生成する

**完了条件:** 「03 で DNS について何を学んだ？」のような質問に、自分のメモを根拠に答える。

### 14-4 `[IaC]` リソースの管理方法を調べる

Vectorize インデックスと AI Gateway を Terraform / wrangler のどちらで作れるかを調べ、選んだ方法で作り直す。
